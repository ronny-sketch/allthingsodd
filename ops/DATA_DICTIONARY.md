# ODD Growth OS — Data dictionary

Canonical field definitions. If Attio (or beehiiv) is ever replaced, this
table — not either vendor's field config — is what a new system gets mapped
to. Enum values live in `schemas/*.yml`; this file is the field-level view
across both forms and both adapters.

**Known drift risk:** `worker/src/validate.ts`'s `PRODUCTS` set is a
hand-maintained copy of `schemas/products.yml`'s values (see the comment in
`worker/src/types.ts` explaining why — no YAML parser in the Worker). If
`schemas/products.yml` changes, `validate.ts` must be updated by hand in the
same commit. There is no automated check for this drift yet — worth adding
if the product list starts changing often.
