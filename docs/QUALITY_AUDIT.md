# ODD Field Guide — Quality Audit

Canonical engineering-quality backlog for the website (Astro/CloudCannon build
under `src/`, `docs/`, `tests/`). Growth OS (`worker/`, `ops/`, `schemas/`,
`data/`) is a separate commercial system — findings that touch it are logged
here for visibility but are out of scope to fix as part of a website pass.

Generated 2026-08-27 via a full-repo audit: static analysis, a live route
crawl (Playwright) at 11 breakpoints × 11 routes, and the existing Playwright
suite run in isolation to separate real regressions from parallel-execution
flakiness. Re-run `npm run quality` (see package.json) to reproduce the
static/build baseline checks below, plus `npm run preview` + `npm test` for
the Playwright suite.

**Corrected 2026-09-01:** `npm run quality` didn't exist in `package.json`
at the time this doc was generated — it was added afterward, defined as
`check && lint && format:check && cc:validate && build` (the same static/
build gates CI's `checks` job runs). The baseline table below also
predates the 2026-08-28 Growth OS repo split; its `worker:check`/
`worker:test` rows describe a `worker/` directory that no longer exists in
this repo (Growth OS's Worker and its own test suite now live in
`../odd-growth-os`, with its own gates — see that repo's `AGENTS.md`) and
should be read as historical, not reproducible from this repo today.
